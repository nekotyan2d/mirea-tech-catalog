# Каталог компьютерной техники

## Назначение

Консольное приложение для учета товаров компьютерной техники на
складе: хранения информации о товарах, отслеживания остатков и
контроля их стоимости.

## Целевая аудитория

Сотрудники небольшого магазина или склада компьютерной техники,
которым нужен простой инструмент учета товаров.

## Предметная область

Учет товаров компьютерной техники: название, категория,
производитель, цена и количество на складе. Приложение позволяет
проверять наличие товара и рассчитывать стоимость остатка.

## Основные сущности

- товар (название, категория, производитель, цена, количество);
- склад (совокупность товаров и их остатков).

## Основные функции

- `is_in_stock` — проверка наличия товара на складе;
- `get_stock_status` — вывод текстового статуса наличия товара;
- `calculate_total_value` — расчет суммарной стоимости остатка товара.

## План развития

На следующих этапах планируется:

- переход от одиночных переменных к коллекциям (списки, словари);
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения и настройка CI/CD.
